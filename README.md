# FruchtPlaner Docs

Documentation page for the FruchtLabor **"FruchtPlaner Discord bot"**, built with [VitePress](https://vitepress.dev/).

## Requirements

- [Node.js](https://nodejs.org/)
- npm

## Setup

```bash
git clone https://github.com/Max1385/FruchtPlaner-Docs.git
cd FruchtPlaner-Docs/fruchtplaner-docs
npm install
npm run dev
```

The site will then be accessible at `http://localhost:5173/`.

## Build

```bash
npm run build
```

> The finished build is placed in `fruchtplaner-docs/build/` and can be hosted as a static site (e.g., using Cloudflare Pages).
