# Private Reminder

## Nach Ausführung des Befehls

Nachdem du den Slash-Command `/reminder` ausgeführt hast, öffnet sich ein **Reminder-Verwaltungs-Menü**. In diesem kannst du Folgendes tun:

- Neue Reminder anlegen
- Liste deiner aktiven Reminder anzeigen
- Alle Reminder löschen
- Eine RRULE testen und Vorschau anzeigen lassen

Bei Auswahl eines Reminders im Auswahlfeld:

- Text, Zeitpunkt oder [RRULE](/allgemein/zeitangaben_wiederholungen) *(custom Wiederholungsregel)* bearbeiten
- Reminder löschen

::: tip Tipp
Du kannst `/reminder` per DM ausführen, damit du die Benachrichtigungen per DM bekommst, oder im Thread-Kanal auf einem Server (Benachrichtigungen dann im Thread).
<br>Mehr Details zu Zeitangaben, RRULE und Wiederholungen: [Klicke hier](/allgemein/zeitangaben_wiederholungen)<br>
:::
::: info Information
Bei erstmaliger Nutzung des Befehls wird dir automatisch ein eigener Thread-Kanal auf dem jeweiligen Server erstellt, in welchem du dann Reminder erstellen kannst.
:::

## Neuen Reminder erstellen
1. Führe den Befehl **`/reminder`** aus, mit welchem du das Menü öffnest. Danach klicke auf den Button **"Erstellen"**.
2. Es öffnet sich ein Eingabefeld, in welchem du den **Titel** deines Reminders sowie den **Zeitpunkt** (wann) angeben musst. Falls du eine RRULE verwenden möchtest, lasse dieses Feld einfach **leer** - du wirst im nächsten Schritt dann aufgefordert, eine RRULE einzutragen.
3. Nun kannst du noch optional eine Wiederholung einrichten. Unter der Nachricht gibt es folgende Aktionen:
    - **Ohne Wiederholung**: Reminder ist dementsprechend nur einmalig und wird nicht noch einmal wiederholt.
    - **Mit Wiederholung (einfache Wiederholung)**: Gib dort den Wiederholungs-Typ (täglich, wöchentlich, monatlich) ein. Falls du stattdessen ein eigenes Intervall (optional) verwenden möchtest, trage dieses in das zweite Feld ein und gib im ersten Feld (Wiederholungs-Typ) `custom` ein.
    - **Mit [RRULE](/allgemein/zeitangaben_wiederholungen) (fortgeschrittene Wiederholung)**: Gib in dieses Feld deine RRULE ein.
    - **Abbrechen**: Die Reminder-Erstellung abbrechen.
