# Hinweis & Bot einladen

## Hinweis des Guides
In diesem Guide wird die Nutzung des `FruchtPlaner#0513`-Bots erklärt.
<br>Durch diesen wird der `/hilfe`-Befehl des Bots somit durch eine detailliertere Version vollständig ersetzt.

## Bot einladen
Nach Absprache mit einem Admin, wird vom Bot-Entwickler selbst ein Einladelink bereitgestellt. Dies ist der Fall, da der Bot (auch im [Discord Developer Portal](https://discord.com/developers/home)) **nicht (!) öffentlich** ist und man ihn somit auch - ohne dass ihn jemand auf *öffentlich* stellt - **nicht** einladen kann.
<br>Der Bot ist **nur** für Server der FruchtLabor-Familie verfügbar.
